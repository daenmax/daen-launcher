# v1.6.8

1. Clipboard window now caches data and rows in memory, so it opens much faster with many records
2. Fixed unsaved note content being lost when hiding the Notes window with the hotkey
3. Fixed quick-added todo text being lost when clicking elsewhere (it is now saved automatically)
4. Fixed the todo "important/delete" icons not rendering on Windows 10 (icon font now adapts to Win10/Win11)
5. Adjusted the 8 todo/note colors for better distinguishability
6. Quick Tools: SM4/AES encryption now supports presets (apply on select, save as preset, manage presets)
7. Settings > Data: export and import Quick Tools presets
8. Launcher: improved favicon fetching (relative paths, <base> tag, SPA routes)
9. Launcher: URL items support a remark field; URLs support ftp, mailto, tel and bare domains
10. Settings window is always kept on top
11. Added app updates: automatic update check, automatic download, update channel (GitHub direct/GitHub proxy)
12. About page: check for updates, release notes, download progress and restart-to-update
