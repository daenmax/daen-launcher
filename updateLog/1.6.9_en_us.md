# v1.6.9

1. Quick Tools: added "Win11 menu style switch" to toggle between the new Win11 context menu and the classic Win10 menu with one click (explorer restarts automatically to apply)
2. Launcher: the edit-item dialog now has a "Run as administrator" option (unchecked by default); when checked, launching the item always requests admin rights
3. Fixed some apps (e.g. Bongo Cat) failing to load their own resources (such as fonts) when started from the launcher: the working directory is now set to the app's own folder
