# Daen Launcher

Daen 的 Windows 快捷启动工具 —— 一个轻量、快速、可高度自定义的 Windows 桌面启动器，基于 WinUI 3 构建，原生 Fluent 设计，支持深浅色主题和云同步。

## 功能特性

### 🚀 快捷启动器

- **分类管理**：项目按"分类 → 子分类"两级组织，分类和子分类均可自定义 emoji 图标（支持自定义输入、上传图片或"不选择"）
- **多种项目类型**：exe 程序、快捷方式（.lnk）、文件、文件夹、网址、自定义协议、UWP 应用，支持直接从桌面 / 资源管理器拖入添加
- **智能图标**：自动提取目标文件/程序的图标并缓存，也可为每个项目自定义图标
- **原生拖拽**：按住项目图标拖动即可排序（带系统原生拖拽动画和让位滑动效果），支持跨子分类移动
- **灵活布局**：平铺 / 列表两种视图，图标大小、横向纵向间距、内容对齐、图标位置、整体对齐全部可调
- **子分类风格**：Tab 标签或卡片两种展示风格，标签支持"经典夹"与"选中高亮"两种样式
- **项目右键菜单**：以管理员身份运行、打开所在位置、复制完整路径、编辑、删除
- **失效检测**：启动时自动检测路径已丢失的项目并显示提示图标
- **搜索 / 重复检测**：添加项目时自动识别类型

### ⌨️ 呼出方式（全局）

- 鼠标**侧键**（前进键 / 后退键）或**中键**单击呼出 / 隐藏
- 连续按两次 **Ctrl** 或 **Alt** 呼出 / 隐藏
- 自定义全局快捷键（默认 Alt+1）
- 系统托盘图标：双击显示主窗口，右键菜单可打开主窗口、设置或退出
- 显示位置可选：跟随鼠标、屏幕中央、上次位置；支持开机自启、启动时静默

### 📋 附属功能

主窗口左下角的功能栏可自由勾选显示的功能（最多 3 个）并排序，其余功能收纳在"⋯"更多菜单中。

#### ✅ 待办事项
- 多标签视图：全部 / 今天 / 重要 / 已完成，支持"今天"快捷筛选过期任务
- 8 种颜色标记 + 重要星标（重要任务可自定义淡色底色）
- 截止日期（含今天 / 明天 / 本周六 / 下周一快捷按钮）、备注
- 快捷添加（行内输入回车即加）与完整弹窗添加两种方式
- **云同步**：通过 [webnote.cc](https://webnote.cc) 便签在多台设备间同步（便签不存在时自动创建）
- 快捷键 Alt+2，支持置顶、锁定尺寸、记忆显示位置

#### 📝 随手记
- 左侧笔记列表（支持置顶、彩色底色），右侧纯文本编辑面板，所有字段直接编辑
- 每条笔记独立同步为一个 webnote 便签，支持多条笔记云同步，与本地数据完全独立、随时切换
- 手动保存按钮，避免高频云端请求
- 快捷键 Alt+3

#### 📎 剪贴板
- 后台监听并记录复制的文本、图片、文件/文件夹，支持缩略图预览
- 点击任意记录即可再次复制，"归档"区不受数量限制持久保存
- 可设置最大记录数量，超出自动裁剪最旧记录；默认关闭，保护隐私
- 快捷键 Alt+4

#### 🧰 常用工具
- 三栏布局：左侧功能分类导航 + 右侧子功能导航，切换工具时输入内容不丢失
- **加解密**：SM4 / AES，支持 CBC / ECB / CFB / OFB / CTR / GCM 模式、7 种填充方式、UTF-8 / Hex / Base64 编码组合，多行批量处理与 Tab 分隔字段处理
- **文本处理**：字符串 MD5、URL 编解码、Base64、换行互转 ('AA','BB','CC')、行去重、字符串替换、大小写转换、文本颠倒、驼峰/下划线互转、文本排序、去首尾空格、删除空白行
- **格式化**：JSON（支持带注释、转义/去转义）、XML（压缩可保留声明、转义/反转义）、SQL 格式化与压缩
- **其他常用**：行求和（支持货币符号/单位）、curl 命令生成（支持 HTTP/SOCKS5 代理）、批量提取文件名（拖拽文件/文件夹）、密码生成、UUID 生成、时间戳互转、颜色选择器（SV 颜色盘 + 屏幕取色，输出 HEX/RGB/HSL/HSV/HWB/LAB/LCH/CMYK）
- 快捷键 Alt+5，支持置顶、锁定尺寸、记忆显示位置

#### 🖼️ 必应每日壁纸
- 整幅圆角大图窗口：自动展示今日必应壁纸 + 日期（如 2026年10月06日）+ 图片描述，点"更换壁纸"一键换到桌面
- **更换成功弹出系统通知**：大图 + 日期 + 图片描述一目了然
- 壁纸尺寸 1080P / 4K，显示模式拉伸 / 适应 / 填充 / 平铺 / 居中 / 跨区，数据来源官方 / biturl 可选，下载域名通用（www）/ 中国（cn）/ 全球（global）可切换
- **每日自动更换**：开机自启后自动获取并更换今日壁纸，当天已换过则跳过（更换记录存 `data\wallpaper\record.json`）
- 可选把每次更换的壁纸按 `日期_尺寸.jpg` 保存到本地目录（缓存目录自动清理，只保留当前壁纸）
- 快捷键 Alt+6，支持置顶、锁定尺寸、记忆显示位置

### ⚙️ 设置

- **常规**：软件标题自定义、开机自启、启动静默、语言（内置简体中文 / English，支持自定义语言包）、附属功能栏配置
- **外观**：深色 / 浅色 / 跟随系统，Mica 等系统窗口材质切换
- **数据**：一键导出 / 导入（zip 包，导入前自动备份，支持软件配置、启动器、待办、随手记、剪贴板、必应壁纸六类数据）、打开配置目录、删除指定数据
- **启动器**：布局、大小、间距、对齐、图标位置、显示触发、启动方式等全部细节
- 所有窗口（主窗口 / 待办 / 随手记 / 剪贴板 / 常用工具 / 必应壁纸 / 设置）统一跟随主题、材质和自定义标题

## 下载使用

1. 前往 [Releases](https://github.com/daenmax/daen-launcher/releases) 下载 `DaenLauncher.exe`
2. 放到你喜欢的任意目录，双击运行即可 —— **单文件、免安装、无需任何运行时**
3. 首次启动后在托盘 / 设置中按需调整呼出方式和快捷键

> 数据存储在 exe 同级的 `data\` 目录（目录不可写时自动回退到 `%LocalAppData%\DaenLauncher\data`），绿色便携，拷走 exe 和 data 文件夹即可迁移。

## 从源码构建

**环境要求**：Windows 10 1809+ / Windows 11，.NET SDK 10.0.401，Visual Studio 2026（或任意带 .NET 10 SDK 的构建环境）

```bat
:: 双击项目根目录的 build.bat
:: 编译为自包含单文件 exe（含全部资源），产物输出到 build\DaenLauncher.exe
```

或使用命令行：

```bash
dotnet publish DaenLauncher/DaenLauncher.csproj -c Release -r win-x64
```

`clean.bat` 可一键清理 bin / obj / build 等编译产物。
